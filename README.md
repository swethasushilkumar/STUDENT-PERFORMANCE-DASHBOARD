# Student Performance Dashboard

## Project Overview
This project presents a Student Performance Dashboard created using Microsoft Power BI to visualize and analyze student performance data.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Project File
The `.pbix` file contains the Power BI dashboard and its report design.

## Objective
To present student performance information in a visual format that makes it easier to understand patterns and compare results.
